客户端回 ACK：ack = y + 1（你的 y 我也收到了），同时带上 seq = x + 1。此后双方都进入 ESTABLISHED，连接建立完成。

双方序列号由此对齐（各自随机选择，避免旧报文造成混淆）

客户端 → 服务端	SYN	x	—
服务端 → 客户端	SYN + ACK	y	x + 1
客户端 → 服务端	ACK	x + 1	y + 1

阅读提示：SYN 表示“我的初始序列号是……”，ACK 表示“你上一条我收到了”。
